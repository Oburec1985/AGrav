# ⚙️ Векторный Индексатор Базы Знаний AGrav

## 🛠 Руководство по запуску и использованию

### Запуск через Python (Синхронизация БЗ вручную)
Для ручного сканирования хранилища и обновления индексов запустите скрипт индексатора из папки `MemoryDB`:
```powershell
# Перейдите в каталог MemoryDB и выполните запуск:
set PYTHONPATH=.
python src/vault_indexer.py
```

### Запуск тестов
```powershell
python src/test_vault_indexing.py
```

### Использование ИИ-агентом (через MCP)
При интеграции `MemoryDB` в IDE как MCP-сервера, агент автоматически получает инструменты:
1. `sync_vault_notes(dry_run=False)` — запуск сканирования и синхронизации.
2. `search_vault_notes(query, limit, project_context)` — семантический поиск чанков заметок по смыслу.
