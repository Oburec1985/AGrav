# 🌐 Инструмент перевода Markdown (AGrav Standard)

Пакетный перевод markdown-файлов с использованием LLM (Gemini 1.5 Flash) с полным сохранением структуры, ссылок и изображений.

---

## 🛠 Запуск
Для перевода используйте скрипт:
```bash
python 00_Система/Инструменты/Перевод_MD/smart_translate_md.py "путь/к/файлу.md" "путь/к/результату_RU.md" --api-key "ВАШ_КЛЮЧ"
```

## 📋 Особенности
- **Stucture Preservation**: Скрипт не трогает блоки кода, ссылки и пути к картинкам.
- **Context Awareness**: Перевод адаптирован под техническую терминологию (DPI, VPN, SQL).
- **Gemini Flash**: Высокая скорость работы и бесплатный лимит.
