# 🛠 Глобальный Технологический Стек AGrav

В репозитории AGrav используются проверенные технологии, обеспечивающие баланс между скоростью разработки, производительностью и надежностью. Ниже приведен обзор основных инструментов и областей их применения.

---

## 1. Бэкенд и Системная логика

### 🐍 Python (FastAPI, Pandas, PDFplumber)
*   **Применение**: Современные веб-сервисы (ALF), парсеры данных (ГТД), OCR-инструменты.
*   **Почему выбрали**: Огромное количество библиотек для работы с данными, высокая скорость написания кода и отличная поддержка асинхронности (FastAPI).

### 🏛 Delphi / Lazarus (Object Pascal)
*   **Применение**: Legacy-системы, высокопроизводительные десктопные компоненты (OpenGL Chart).
*   **Почему выбрали**: Нативная скорость, работа с памятью на низком уровне, огромный опыт накопленных библиотек предприятия.

---

## 2. Фронтенд и Визуализация

### ⚛️ React / Next.js
*   **Применение**: Основной UI для веб-приложений (ALF, SQLSensorsDB).
*   **Почему выбрали**: Компонентный подход, высокая производительность отрисовки и отличная экосистема для карт и дашбордов.

### 🗺 Leaflet / MapLibre
*   **Применение**: Работа с интерактивными картами.
*   **Почему выбрали**: Легкость интеграции с OpenStreetMap и гибкость в отображении тысяч маркеров в реальном времени.

---

## 3. Работа с данными

### 🐘 PostgreSQL + PostGIS
*   **Применение**: Хранение сложных реляционных и географических данных.
*   **Почему выбрали**: Надежность промышленного стандарта и уникальные возможности PostGIS для мгновенного поиска объектов по координатам.

### 📊 Excel / Pandas
*   **Применение**: Промежуточная обработка таблиц и генерация отчетов.
*   **Почему выбрали**: Excel остается главным интерфейсом для бизнес-пользователей; Python позволяет автоматизировать работу с ним без ошибок ручного ввода.

---

## 4. Инфраструктура и Деплой

### 🐳 Docker / Docker Compose
*   **Применение**: Изоляция и запуск всех сервисов (ALF, БД, Боты).
*   **Почему выбрали**: Принцип «Запуск одной кнопкой». Контейнеры гарантируют, что проект запустится на любом ПК без конфликтов версий библиотек.

#### 💡 Как это работает (Deep Dive):

1.  **Docker vs Виртуальная машина (VM)**:
    *   **VM**: Клонирует *всё* — от ядра операционной системы до драйверов. Это тяжело и медленно.
    *   **Docker**: Не клонирует ОС. Он использует **ядро вашей Windows** (через слой WSL2), но создает изолированную "коробку" для системных библиотек. Это как запуск приложения в отдельной песочнице, которая думает, что она — Linux.

2.  **Почему код на диске обновляется в Docker? (Volumes)**:
    *   Вы редактируете код в обычной папке Windows. В файле `docker-compose.yml` прописана связь (Bind Mount): `host_path : container_path`.
    *   Docker не копирует эти файлы внутрь контейнера навсегда. Он создает **виртуальную ссылку**. Контейнер «смотрит» прямо на вашу папку на жестком диске. Как только вы нажали `Ctrl+S`, Docker-процесс внутри контейнера мгновенно видит новый байт в файле.

3.  **Что внутри контейнера?**:
    *   **НЕ клонируется**: Реестр Windows, графическая оболочка, драйверы оборудования.
    *   **Изолируется**: Системные библиотеки Linux (glibc), интерпретатор Python, все зависимости из `requirements.txt` и переменные окружения.
    *   **Контроль**: Все управление идет через **Docker Desktop** (визуально) или команды `docker ps`, `docker logs`.

4.  **Как Docker понимает, что копировать?**:
    *   **Dockerfile**: Это инструкция «сборки». Здесь мы пишем `COPY requirements.txt .`. Это копируется в образ *навсегда*.
    *   **.dockerignore**: Аналог `.gitignore`. Здесь мы пишем `venv/` или `__pycache__/`, чтобы Docker НЕ тащил внутрь мусор и тяжелые папки с хоста.
    *   **Docker Compose**: Если в Compose указан `volumes`, то Docker «накрывает» внутреннюю папку вашей папкой с Windows. Это позволяет не копировать код каждый раз при изменении.

5.  **Где живет База Данных?**:
    *   В AGrav база данных **полностью изолирована**. Вам не нужно устанавливать PostgreSQL на Windows. 
    *   Docker сам скачивает образ `postgis/postgis`, внутри которого уже есть всё необходимое. 
    *   **Данные не пропадают**: Мы используем **Named Volumes** (`db_data:/var/lib/postgresql/data`). Это специальная область памяти, которую Docker держит отдельно. Даже если вы удалите все контейнеры, данные вашей базы останутся в этом «сейфе» и подцепятся обратно при новом запуске.

### 📦 PyInstaller
*   **Применение**: Создание портативных EXE-файлов из Python-скриптов.
*   **Почему выбрали**: Позволяет передавать инструменты пользователям, у которых не установлен Python (актуально для парсеров ГТД и ЗП).

## 5. Безопасность и Интеграции

*   **JWT (JSON Web Tokens)**: Безопасная авторизация без хранения состояния на сервере.
*   **Telegram API**: Уведомления пользователей в реальном времени там, где им удобно.
*   **SMTP**: Официальная почтовая рассылка для верификации аккаунтов.
