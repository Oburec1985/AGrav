# 🧠 Системный навык: Выполнение и поиск RLM (Recursive Language Models)

Этот навык описывает протокол интерактивного выполнения кода, математических расчетов, рефакторинга и поиска информации по базе знаний **AGrav** и исходным кодам проектов с использованием паттерна **RLM**.

---

## 🎯 Сфера применения RLM

RLM — это не только инструмент поиска, но и универсальный вычислительный контур. Он применяется для:
1. **Сложных вычислений**: Расчет параметров, калибровка датчиков, парсинг логов.
2. **Генерации и верификации кода**: Написание скриптов, их выполнение в REPL для проверки корректности, исправление ошибок на основе вывода компилятора/интерпретатора.
3. **Глубокого рефакторинга**: Итеративный анализ связей между классами и автоматическая перестройка структуры.
4. **Сверхдлинного контекста**: Чтение и обработка файлов объемом более 100 тыс. токенов без потери фокуса.

---

## 🛠️ Протокол выполнения (Алгоритм для ИИ)

При переходе в режим RLM ИИ работает в интерактивном цикле выполнения кода:

### Шаг 1: Инициализация песочницы
ИИ представляет наличие изолированной песочницы Python со следующими переменными:
* `context` — целевые данные (код проекта, файлы базы знаний, структуры).
* `answer = {"content": "", "ready": False}` — объект фиксации ответа/результата.

### Шаг 2: Написание кода и вычисления (REPL Loop)
Вместо ручного анализа ИИ пишет Python-код для автоматизации задачи.
*Пример (расчет контрольной суммы и генерация заголовка файла):*
```python
# Расчет контрольной суммы CRC16 для проверки целостности конфига
def crc16(data: bytes) -> int:
    crc = 0xFFFF
    for byte in data:
        crc ^= byte
        for _ in range(8):
            if crc & 1:
                crc = (crc >> 1) ^ 0xA001
            else:
                crc >>= 1
    return crc

config_data = context.encode('utf-8')
calculated_crc = crc16(config_data)
print(f"CRC16: {hex(calculated_crc)}")
```

### Шаг 3: Локальный вызов моделей (`llm_query`)
Для обработки локальных кусков или формулирования выводов ИИ вызывает вспомогательную модель:
```python
# Суммаризация изменений в коде класса
class_summary = llm_query("Опиши изменения в этом классе", extract_class_code(context))
```

### Шаг 4: Рекурсивный запуск подзадач (`rlm_query`)
Если в процессе вычислений требуется решить вложенную задачу (например, сгенерировать юнит-тест для нового метода), ИИ запускает дочернего RLM-агента:
```python
if test_needed:
    test_code = rlm_query("Сгенерируй JUnit тест для метода calculateCRC")
```

### Шаг 5: Запись и возврат результата
После завершения расчетов/генерации ИИ записывает итоговые данные:
```python
answer["content"] = "Скрипт успешно проверен. Сгенерированный код тестов: ..."
answer["ready"] = True
```

## ⚠️ Правила ограничений (Safety Guards)
1. **Глубина рекурсии** (`max_depth`) $\le 3$.
2. **Количество итераций цикла** (`max_steps`) $\le 5$.
3. **Безопасность выполнения**: Запрещено выполнять деструктивный код (удаление файлов вне песочницы, сетевые атаки). Вся работа ведется в изолированном окружении.
