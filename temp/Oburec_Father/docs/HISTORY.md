### 1. Что сделано:
- **Установка Zapret**: Пакет установлен на роутер `192.168.3.1` (папка `/opt/zapret`).
- **Разрешение конфликта**: 
  - Zapret переведен на метку **`0x2`** (`DESYNC_MARK=0x2`).
  - ZeroBlock остается на метке **`0x40000000`**.
  - Теперь они работают параллельно без зацикливания трафика.
- **Стратегия YouTube**:
  - Применен метод **`disorder`** для TCP 443 (фрагментация/перемешивание пакетов).
  - Применен метод **`fake`** для UDP 443 (обход QUIC).
- **Оптимизация**: Отключен IPv6 в конфиге Zapret для предотвращения утечек.

### 2. Текущий статус:
- **Zapret**: Работает (процесс `nfqws` запущен).
- **YouTube**: DPI-обход активен.
- **ZeroBlock**: Продолжает работать как прокси/VPN для остальных ресурсов.
