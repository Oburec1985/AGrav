## 📖 Обзор ZeroBlock
ZeroBlock – это кастомная прошивка на базе **OpenWrt**, оптимизированная под обход интернет‑цензуры в РФ. Она поддерживает:
- **DNS‑over‑TLS (DoT)** и **DNS‑over‑HTTPS (DoH)**
- **VPN‑клиенты** (WireGuard, OpenVPN)
- **Smart DNS** (для YouTube, Netflix, Telegram)
- Гибкие правила фаервола через `iptables`/`nftables`

---

## ✅ Требования
1. **Маршрутизатор** с поддержкой прошивки ZeroBlock (обычно модели Xiaomi/TP‑Link/GL‑iNet).
2. **Компьютер** в той же сети для доступа к веб‑интерфейсу роутера.
3. **Лицензионный доступ к DNS‑серверу**, который не блокируется (например, 1.1.1.1, 8.8.8.8, либо публичный DoT‑сервер Cloudflare `1.1.1.1:853`).
4. **Ключи WireGuard** (если планируется VPN‑обход), но в базовой конфигурации они не обязательны.

## ⬇️ Обновление прошивки (если требуется)
```bash
# 1. Скачайте последнюю сборку ZeroBlock для вашей модели
wget -O /tmp/zeroblock.bin https://downloads.zeroblock.io/latest/zeroblock_<model>.bin

# 2. Через веб‑интерфейс → System → Backup / Flash Firmware → выберите файл и нажмите "Flash".
# 3. Дождитесь завершения и роутер автоматически перезагрузится.
```
> **Важно:** Не отключайте питание роутера во время прошивки.

## 🌐 Настройка DNS (ключ к обходу блокировок)
1. **System → Network → Interfaces → WAN**
   - `Protocol`: `DHCP` (по‑умолчанию)
   - В поле **Use custom DNS servers** введите:
     ```
     1.1.1.1
     1.0.0.1
     8.8.8.8
     8.8.4.4
     ```
2. **System → Network → DHCP and DNS → General Settings**
   - Установите **DNS forwarder** в `dnsmasq` (по‑умолчанию).
   - Включите **DNS over TLS**:
     ```
     option 'dns_over_tls' '1'
     list 'tls_server' '1.1.1.1#853'
     list 'tls_server' '8.8.8.8#853'
     ```
3. Сохраните и **перезапустите** службу DNS: `service dnsmasq restart`.

## 🔥 Фаервол и правила NAT
```bash
# Откройте порт 443 (HTTPS) для входящего трафика – нужен для DoT/DoH
iptables -A INPUT -p tcp --dport 443 -j ACCEPT

# Разрешаем UDP 53 (DNS) только к выбранным серверам
iptables -A OUTPUT -p udp -d 1.1.1.1 --dport 53 -j ACCEPT
iptables -A OUTPUT -p udp -d 8.8.8.8 --dport 53 -j ACCEPT

# Блокируем DNS‑запросы к другим публичным серверам (защита от утечек)
iptables -A OUTPUT -p udp --dport 53 -j DROP
```
> Добавьте правила в **Network → Firewall → Custom Rules**.

## 📺 Оптимизация для YouTube (Zapret + ZeroBlock)
Для стабильной работы YouTube мы используем гибридную схему: **Zapret** (для обхода DPI) + **ZeroBlock** (для проксирования всего остального).

### 1. Настройка Zapret (DPI Bypass)
Сервис `zapret` (nfqws) настроен на работу с меткой `0x2`.
- **Конфиг:** `/opt/zapret/config`
- **Ключевые параметры:**
  - `DESYNC_MARK=0x2` (защита от конфликта с ZeroBlock)
  - `NFQWS_OPT`: Используется стратегия `disorder` для TCP/443 и `fake` для UDP/443 (QUIC).
- **Команды управления:**
  ```bash
  /etc/init.d/zapret restart  # Перезапуск после смены настроек
  ps | grep nfqws             # Проверка, что процесс запущен
  ```

### 2. Настройка ZeroBlock (Sing-box)
Чтобы Zapret мог обрабатывать YouTube, ZeroBlock **НЕ должен** направлять его в прокси.
- **Действие:** В интерфейсе ZeroBlock добавьте домены `youtube.com`, `googlevideo.com`, `ytimg.com` в список **Direct** (Прямо).
- **Метка ZeroBlock:** `0x40000000` (не менять).

### 3. Telegram
- Telegram по-прежнему лучше работает через прокси/VPN в ZeroBlock.
- Убедитесь, что он **НЕ** в списке Zapret, чтобы избежать двойной обработки.

## 🧪 Тестирование
1. **Проверьте DNS:** `nslookup youtube.com` – адрес должен резолвиться быстро и без ошибок.
2. **YouTube:** Откройте видео в браузере; если поток загружается без "Ошибка доступа", всё работает.
3. **Telegram:** Откройте приложение и отправьте сообщение; отсутствие ошибки "Не удалось подключиться" подтверждает настройку.
4. **Проверка блокировки:** зайдите на https://check.rkn.gov.ru/ – если сайт доступен, обход работает.

## 🛠️ Решение проблем
| Признак | Возможная причина | Шаги исправления |
|----------|-------------------|------------------|
| DNS‑запросы падают | Фаервол блокирует 53/UDP к выбранным DNS | Проверьте `iptables` правила, уберите `DROP` для нужных IP. |
| YouTube «не загружается» | MTU слишком большой | Снизьте MTU до 1492 или 1450. |
| Telegram «соединение не установлено» | Порт 443 закрыт | Убедитесь, что правило `ACCEPT` для `tcp/443` существует. |
| Сайт check.rkn.gov.ru недоступен | DNS‑переправление всё ещё использует провайдерский DNS | Очистите кэш `dnsmasq` (`/etc/init.d/dnsmasq restart`). |

## 📋 Итоги
- **ZeroBlock** → прошивка, обновление.
- **DNS‑over‑TLS/DoH** → 1.1.1.1, 8.8.8.8.
- **Фаервол** → открыты порты 443 (TCP/UDP) и 53 (UDP) только к выбранным DNS.
- **MTU** → 1492 для видеопотоков.
- **Опционально:** WireGuard для полного туннелирования.

Следуя данной инструкции, ваш роутер будет стабильно работать, а доступ к YouTube, Telegram и другим ресурсам, блокируемым РКН, будет сохраняться.
