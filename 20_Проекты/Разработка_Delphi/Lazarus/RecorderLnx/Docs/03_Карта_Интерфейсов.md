# RecorderLnx: карта интерфейсов Windows Recorder

Источник: `D:\works\OburecGH\recorder\SharedRUnits\interfaces`.

Эта карта нужна, чтобы при проектировании RecorderLnx не дублировать уже найденные сущности и не терять функционал Windows Recorder. Это не требование переносить COM API один к одному. Это функциональный каталог.

## Ключевые интерфейсы

| Файл | Интерфейсы / типы | Назначение для RecorderLnx |
| --- | --- | --- |
| `recorder.pas` | `IRecorder`, `IVForm`, `ISettingsINI`, `IUserProperties`, `RECORDERSTATE`, команды `RCN_*`, свойства `RCPROP_*` | Центральный фасад Recorder: состояние, теги, группы, устройства, формуляры, свойства, окружение, уведомления. Основа для `TRecorderCore` и `IRecorderCore`. |
| `plugin.pas`, `rcPlugin.pas` | `IRecorderPlugin`, `PLUGININFO`, `RCNOTIFY`, события `PN_*` | Жизненный цикл плагинов, уведомления, конфигурация, запуск/останов, обработка обновлений данных. Основа для новой plugin API без COM. |
| `tags.pas` | `ITag`, `ITagsGroup`, `ITagBlockVectorControl`, `TAGPROP_*`, `TN_*` | Измерительные каналы, группы каналов, свойства тегов, запись, push данных, синхронное чтение, оценки, диапазоны, связь с источниками. Основа для `TTag`, `TTagRegistry`, `TTagGroup`. |
| `signal.pas` | `ISignal` | Буфер/сигнал: X/Y данные, размер, трансформер, диапазоны, min/max, масштабирование, блокировки данных. Основа для `TSignalBuffer`. |
| `device.pas` | `IDevice`, `ICrateDevice`, `IEntity` | Слой устройств: свойства, crate/слоты/модули, чтение/запись регистров и flash. Основа для дерева устройств и источников данных. |
| `modules.pas` | `IModule` | Модуль устройства: тип, свойства, reset, командный вызов. Основа для адаптеров аппаратных модулей. |
| `DevAPI.pas` | `IAnalogOutput`, `IDigitalInput`, `IDigitalOutput` | Специализированные каналы ввода/вывода. Нужны как справка для будущих источников и управляющих выходов. |
| `CFREG.PAS` | `ICustomFormFactory`, `ICustomFormsRegistrator`, `ICustomButtonsToolBar`, `ICustomButtonsControl` | Расширяемые формуляры и кнопки UI. Основа для менеджера формуляров и фабрик LCL-форм без COM. |
| `IVFORM.PAS` | `IVForm` | Альтернативное/старое объявление формуляра. Сверять с `recorder.pas`. |
| `uAlarms.pas` | `IAlarm`, `IAlarmHolder`, `IAlarmEvent`, `IAlarmsHandler`, `IAlarmEventHandler`, `IAlarmsControl` | Уставки, события тревог, триггеры записи, обработчики событий. Основа будущего alarm subsystem. |
| `scales.pas` | `IMeScaleEval`, `IMeScaleEdit`, `IMeScaleProp`, `IMeScaleLinear`, `IMeScaleInterpolate`, `IMeScalePolynomial`, `IMeScaleCSV`, `IMeScaleMERA`, `IMeScaleBIN` | Тарировки/шкалы/пересчёты. Основа библиотеки трансформации значений. |
| `transf.pas`, `transformers.pas` | `ITransformer`, `IScale`, `IInterpolate`, `ILinear`, `IPolynomial` | Математические трансформеры данных: scale, linear, interpolation, polynomial. Нужно унифицировать со `scales.pas`. |
| `sdb.pas`, `sdbview.pas` | `IMeSDBBase`, `IMeSDBScale`, `IMeSDBFolder`, `IMeSDBObjectMgr`, `IMeSDBViewer`, node-интерфейсы | База/каталог шкал и viewer. Может стать отдельным модулем калибровок/справочников. |
| `journal.pas` | `IJournal`, `JOURNALEVENT` | Журнал событий. Основа системного и пользовательского логов. |
| `iplgmngr.pas` | `IPluginsControl`, `PLUGINCONTEXT` | Управление плагинами: список, автозагрузка, создание, конфигурация, запуск, закрытие. Основа `TPluginManager`. |
| `blaccess.pas` | `IBlockAccess`, `UTSPAIR`, `I2PAIR`, `R8PAIR` | Блочный доступ к данным/парам значений. Уточнить при проектировании хранения и обмена. |
| `waitwnd.pas` | `IWaitingWindow` | Окно ожидания/прогресса. В RecorderLnx заменить LCL-сервисом прогресса. |
| `meconsts.pas` | `IMeProcessNotifySink` | Уведомления длительных процессов: ошибка/прогресс. Основа `IProgressSink`. |
| `GUIDDEF.PAS` | `GUID`, `_GUID` | Windows GUID. В новом ядре использовать FPC `TGUID`, но не тащить Windows-only unit без необходимости. |

## Функциональные группы будущего ядра

### Ядро приложения

Будущие сущности: `IRecorderCore`, `TRecorderCore`, `TRecorderStateMachine`, `TRecorderEnvironment`, `TRecorderCommandBus`.

Соответствие Windows Recorder: `IRecorder`, `RCN_*`, `RCPROP_*`, `RECORDERSTATE`.

### Данные и каналы

Будущие сущности: `TTag`, `TTagId`, `TTagRegistry`, `TTagGroup`, `TSignalBuffer`, `TDataFrame`.

Соответствие Windows Recorder: `ITag`, `ITagsGroup`, `ISignal`, `TAGPROP_*`, `TN_*`.

### Устройства и источники данных

Будущие сущности: `TDeviceTree`, `TDeviceNode`, `TDataSourceNode`, `IDataSource`, `TDataSourceThread`, `TDataSourceSnapshot`.

Соответствие Windows Recorder: `IDevice`, `ICrateDevice`, `IModule`, `DevAPI`.

### Формуляры и UI

Будущие сущности: `IRecorderForm`, `TRecorderFormFrame`, `TFormManager`, `IFormFactory`, `TVisualSchemeDocument`.

Соответствие Windows Recorder: `IVForm`, `ICustomFormFactory`, `ICustomFormsRegistrator`, `ICustomButtonsToolBar`.

### Плагины

Будущие сущности: `IRecorderPlugin`, `TPluginManager`, `TPluginDescriptor`, `TPluginHostApi`, `.so` ABI layer.

Соответствие Windows Recorder: `IRecorderPlugin`, `IPluginsControl`, `PLUGININFO`, `PN_*`.

### Уставки и события

Будущие сущности: `TAlarm`, `TAlarmManager`, `IAlarmHandler`, `TAlarmEvent`.

Соответствие Windows Recorder: `IAlarm*`, `IAlarmsControl`.

### Шкалы и преобразования

Будущие сущности: `IScaleTransform`, `TLinearScale`, `TInterpolationScale`, `TPolynomialScale`, `TScaleRepository`.

Соответствие Windows Recorder: `scales.pas`, `transf.pas`, `transformers.pas`, `sdb.pas`.
