# RecorderLnx

RecorderLnx — проект нативного Linux-приложения на Lazarus/FPC для сбора, отображения, записи и обработки данных от различных измерительных систем.

Проект создаётся как системная переработка идей Windows Recorder без прямой зависимости от COM и неподконтрольных бинарных компонентов. Базовый источник анализа существующего функционала: `D:\works\OburecGH\recorder\SharedRUnits\interfaces`.

## Цели

## Рабочие каталоги

- Исходники: `D:\works\OburecGH\Lazarus\RecorderLnx\`.
- Общий код Lazarus: `D:\works\OburecGH\Lazarus\SharedUtils\`.
- Тесты-примеры: `D:\works\OburecGH\Lazarus\Tests\RecorderTests\`.

## Процесс разработки

Перед написанием кода по каждому новому функционалу сначала задаём наводящие вопросы, согласуем поведение и пример/тест, затем реализуем. Это обязательное правило проекта RecorderLnx.

- Сбор данных из нескольких измерительных систем с собственными периодами обновления.
- Отображение данных на множестве формуляров/мнемосхем в UI-потоке.
- Запись измерительных данных в режиме регистрации.
- Расширяемость внешними модулями, желательно без пересборки основного приложения.
- Строгий реестр библиотек, классов и интерфейсов, чтобы не дублировать уже написанный функционал.

## Основные режимы

- `Stop` — конфигурирование проекта, устройств, источников данных, формуляров, плагинов.
- `View` / `Data acquisition` — сбор и отображение данных без записи.
- `Record` — сбор, отображение и сохранение данных.
