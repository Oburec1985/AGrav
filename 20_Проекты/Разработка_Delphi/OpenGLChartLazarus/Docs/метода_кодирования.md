# Метод изменения исходных файлов Delphi/Lazarus с сохранением кодировки Windows-1251 и окончаний строк CRLF

Для предотвращения искажения кириллицы (кодировки `CP1251`) и изменения окончаний строк при редактировании файлов проекта встроенными средствами AI-ассистента, используется следующий двухэтапный метод:

1. **Запись временного файла в UTF-8**:
   Ассистент записывает отредактированное содержимое модуля во временный файл с суффиксом `.utf8.pas` (используя стандартные механизмы записи UTF-8).

2. **Перекодирование и нормализация CRLF через PowerShell**:
   Выполняется PowerShell-команда, которая считывает временный файл в UTF-8, заменяет все окончания строк на `CRLF` (`\r\n`), и перезаписывает целевой `.pas` файл в кодировке `Windows-1251` (без BOM):

   ```powershell
   powershell -Command "[System.IO.File]::WriteAllText('C:\Путь\К\Файлу.pas', [System.IO.File]::ReadAllText('C:\Путь\К\Файлу.pas.utf8', [System.Text.Encoding]::UTF8).Replace([string]([char]13 + [char]10), [string][char]10).Replace([string][char]10, [string]([char]13 + [char]10)), [System.Text.Encoding]::GetEncoding(1251))"
   ```

3. **Удаление временного файла**:
   ```powershell
   Remove-Item 'C:\Путь\К\Файлу.pas.utf8'
   ```

## Тестовый файл
Тестовый файл `uTestRussianText.pas` успешно закодирован данным методом и содержит корректные русские комментарии в cp1251 с окончаниями строк CRLF.
