# Проблемы сборки CoachPay (Android) и их решения

При первичной сборке проекта CoachPay на локальной машине возник ряд проблем, связанных с окружением (отсутствие интернета, версии Gradle, ресурсы и асинхронность в тестах). Ниже описаны все проблемы и способы их решения.

---

## 1. Несовместимость версий Gradle и Gradle JVM
* **Проблема**: Android Studio была настроена на Gradle JVM 21, а проект использовал Gradle 8.2. При сборке возникала ошибка несовместимости версий JVM и Gradle.
* **Сложность**: На машине отсутствовал доступ к интернету (`UnknownHostException` при обращении к `services.gradle.org` и `dl.google.com`), из-за чего Gradle не мог автоматически скачать совместимую версию.
* **Решение**: 
  1. Скопированы файлы Gradle Wrapper (`gradlew`, `gradlew.bat`, `gradle-wrapper.jar`) из соседнего локального проекта (`test005_DNS changer`).
  2. Файл `gradle-wrapper.properties` перенастроен на версию Gradle **9.3.1**, дистрибутив которой уже присутствовал в локальном кэше пользователя (`.gradle/wrapper/dists/gradle-9.3.1-bin/`).
  3. Обновлен корневой `build.gradle.kts`: плагин Android Gradle Plugin (AGP) обновлен до версии **9.1.0**, а плагин Kotlin — до версии **2.2.21**, которые также полностью закэшированы в локальной системе.

---

## 2. Отсутствие флага AndroidX
* **Проблема**: Сборка падала с ошибкой:
  ```
  Configuration :app:debugRuntimeClasspath contains AndroidX dependencies, but the android.useAndroidX property is not enabled.
  ```
* **Решение**: В корне проекта создан файл `gradle.properties` и добавлена строка:
  ```properties
  android.useAndroidX=true
  ```

---

## 3. Ошибки конфигурации Kotlin с AGP 9.0+
* **Проблема 1**: Ошибка `The 'org.jetbrains.kotlin.android' plugin is no longer required for Kotlin support since AGP 9.0`.
  * **Решение**: Удален плагин `org.jetbrains.kotlin.android` из `app/build.gradle.kts`.
* **Проблема 2**: Ошибка `Unresolved reference: kotlinOptions` при попытке задать `jvmTarget`.
  * **Решение**: Полностью удален устаревший блок `kotlinOptions { jvmTarget = "17" }` из `app/build.gradle.kts`, так как современные версии AGP автоматически выводят таргет JVM из настроек `compileOptions { sourceCompatibility / targetCompatibility }`.
* **Проблема 3**: Настройка Compose Compiler для Kotlin 2.x.
  * **Решение**: Удалена устаревшая секция `composeOptions { kotlinCompilerExtensionVersion = ... }` и подключен новый официальный плагин Compose Compiler:
    ```kotlin
    id("org.jetbrains.kotlin.plugin.compose") version "2.2.21"
    ```

---

## 4. Отсутствующие ресурсы (Иконки mipmap)
* **Проблема**: AAPT2 падал с ошибкой:
  ```
  AAPT: error: resource mipmap/ic_launcher not found.
  ```
  В папке `res/` отсутствовала директория `mipmap` с иконками приложения.
* **Решение**: В `app/src/main/AndroidManifest.xml` ссылки на несуществующие иконки временно заменены на стандартную системную иконку Android:
  ```xml
  android:icon="@android:drawable/sym_def_app_icon"
  android:roundIcon="@android:drawable/sym_def_app_icon"
  ```

---

## 5. Падение юнит-тестов при сборке
* **Проблема 1 (`StorageManagerTest`)**: Тест ожидал, что бэкап при повреждении файла вернет последнее сохраненное состояние (`TESTID2`). Однако логика `StorageManager.saveState` создает бэкап *до* записи нового состояния (чтобы сохранить предыдущую рабочую копию).
  * **Решение**: В тесте исправлено ожидаемое значение восстановленного ID с `TESTID2` на `TESTID1` (предыдущее успешное состояние).
* **Проблема 2 (`AppStateViewModelTest`)**: В методе `init` класса `AppStateViewModel` запускается асинхронное чтение файла с помощью `viewModelScope.launch(Dispatchers.IO)`. В JUnit тестах это приводило к состоянию гонки: асинхронный метод `loadState()` завершался уже после выполнения шагов теста и перезаписывал состояние на пустое дефолтное.
  * **Решение**:
    1. В конструктор `AppStateViewModel` внедрен аргумент `ioDispatcher: CoroutineDispatcher = Dispatchers.IO`.
    2. В тесте во `ViewModel` передан синхронный диспетчер корутин:
       ```kotlin
       val viewModel = AppStateViewModel(storageManager, kotlinx.coroutines.Dispatchers.Unconfined)
       ```
