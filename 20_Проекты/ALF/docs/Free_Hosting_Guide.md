# Руководство по хостингу проекта ALF

Этот документ описывает варианты запуска проекта с учетом технических возможностей и законодательства РФ (152-ФЗ «О персональных данных»).

> [!IMPORTANT]
> **Юридическое примечание:** Поскольку ALF собирает персональные данные (email, телефоны), согласно 152-ФЗ и вашей Политике конфиденциальности (п. 4.2), первичная обработка и хранение данных **обязаны** происходить на территории РФ.

## Вариант А: Российский сегмент (Юридическая чистота)
Рекомендуется для официального запуска в России.

1.  **Amvera Cloud** (amvera.ru):
    *   **Преимущества:** Аналог Render/Heroku, серверы в РФ. Простой деплой через Git.
    *   **Тариф:** Есть пробный период/баланс.
2.  **Cloud.ru / Yandex Cloud**:
    *   **Преимущества:** Промышленные стандарты. Дают гранты (до 4000 руб) новым пользователям, чего хватит на несколько месяцев бесплатной работы.
3.  **Timeweb / Beget**:
    *   **Преимущества:** Самые дешевые VPS (от 170 руб/мес). Требуют ручной настройки Docker.

## Вариант Б: Международные сервисы (Для тестов)
*Использовать только для демонстрации без реальных данных пользователей РФ.*

*   **База данных:** [Neon.tech](https://neon.tech) (Бесплатный управляемый Postgres).
*   **Бэкенд:** [Render.com](https://render.com) (Бесплатные Web Services).
*   **Фронтенд:** [Vercel.com](https://vercel.com) (Лучший хостинг для Next.js).

## Технические шаги для деплоя (универсально):

### 1. База данных
Если используете Docker-версию на VPS:
```bash
# Docker сам поднимет БД из docker-compose.yml
```
Если используете облачную БД (Managed Postgres):
1. Получите строку подключения `DATABASE_URL`.
2. Пропишите её в переменных окружения хостинга.

### 2. Хранение изображений
При хостинге в облаке локальная папка `static/uploads` будет стираться при каждом обновлении кода.
*   **Решение:** Подключите **Cloudinary** или **Selectel Storage** (РФ).
*   Требуется обновить функцию `upload_image` в `main.py`.

### 3. Переменные окружения (ОБЯЗАТЕЛЬНО)
На любом хостинге настройте следующие секреты:
- `DATABASE_URL`: Доступ к базе.
- `SECRET_KEY`: Ключ для JWT-токенов.
- `NEXT_PUBLIC_API_URL`: Адрес вашего бэкенда (например, `https://api.alf.amvera.ru`).
