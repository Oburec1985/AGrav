# Отчет о статусе разработки ALF (03.05.2026 - 04.05.2026)

## Текущий прогресс: Система безопасности и профили пользователей

### 1. Авторизация и Безопасность
- **JWT-аутентификация**: Внедрена полноценная система входа на базе OAuth2 и JWT токенов.
- **Хеширование паролей**: Используется алгоритм `sha256_crypt` (устранены ограничения bcrypt на длину пароля).
- **Верификация Email**: Реализована обязательная активация аккаунта через ссылку в письме.
- **SMTP Интеграция**: Настроена отправка писем через внешние серверы (Mail.ru и др.).
- **Очистка данных**: Добавлена фоновая задача, удаляющая неподтвержденные профили через 24 часа.

### 2. Управление контентом
- **Привязка объявлений**: Все новые объявления теперь привязываются к `owner_id` авторизованного пользователя.
- **Автозаполнение**: При создании объявления данные (имя, контакты) подтягиваются из профиля.
- **Приватность**: Добавлена настройка «Показывать контакты по умолчанию», которую пользователь может менять в профиле.
- **Разделение прав**: Владелец видит кнопки редактирования и статистику (отклики) сразу после входа, без ввода отдельного пароля на каждое объявление.

### 3. Инфраструктура
- **Миграции БД**: Скрипт `init_db.py` теперь автоматически обновляет схему таблиц при запуске (добавляет новые колонки без потери данных).
- **Утилиты**: Создан `restart_alf.bat` для быстрого обновления и пересборки проекта с учетом новых зависимостей.

## Планы на следующий этап:
1. **Личный кабинет**: Страница со списком всех «Моих объявлений».
2. **Система сообщений**: Внутренний чат между пользователями (замена простому просмотру контактов).
3. **Уведомления**: Интеграция с Telegram-ботом для мгновенных оповещений о новых откликах.

### 4. Новые функции
- **Транспортные находки**: Добавлена возможность указывать тип транспорта и маршрут (откуда-куда) для вещей, потерянных в пути.
- **Расширенный поиск**: Поиск теперь учитывает информацию о транспорте. Реализована логика пересечения (**И** через пробел) и объединения (**ИЛИ** через `|`), что позволяет точно комбинировать условия (например, "маршрут 101 синий кошелек").
