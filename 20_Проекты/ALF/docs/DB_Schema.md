# Схема базы данных ALF (Lost & Found)

В проекте используется PostgreSQL с расширением **PostGIS** для работы с географическими координатами.

---

## 1. Таблица `items` (Объявления)
Основная таблица системы, хранящая информацию о потерянных и найденных вещах.

| Имя поля | Тип | Значение / Пример | Примечание |
| :--- | :--- | :--- | :--- |
| `id` | Integer | `42` | Первичный ключ |
| `title` | String | `"Пропала собака"` | Краткий заголовок |
| `description` | Text | `"Черный лабрадор, был в..."` | Полное описание |
| `category` | String | `"cat_pets_dog"` | Слаг категории (для совместимости) |
| `category_id` | Integer | `5` | Ссылка на таблицу `categories` |
| `type` | Enum | `LOST` / `FOUND` | Тип: Потеряно или Найдено |
| `status` | Enum | `ACTIVE` / `RETURNED` | Статус (активно, возвращено, архив) |
| `location` | Geometry | `POINT(37.6 55.7)` | Координаты (PostGIS POINT) |
| `location_str` | String | `"Метро Таганская"` | Название места текстом |
| `image_url` | String | `http://.../photo.jpg` | Ссылка на основное фото |
| `reward_info` | String | `"Вознаграждение 5000р"` | Инфо о награде |
| `is_contact_public`| Boolean| `true` / `false` | Видны ли контакты всем |
| `contact_phone` | String | `"+79991234567"` | Телефон для связи |
| `contact_email` | String | `"user@mail.ru"` | Почта для связи |
| `owner_telegram_id`| String | `"123456789"` | ID для уведомлений в Telegram |
| `edit_password` | String | `"secret123"` | Пароль для управления анонимным постом |
| `owner_id` | Integer | `10` | Ссылка на `users.id` (если зарегистрирован) |
| `event_date` | DateTime | `2024-05-08 12:00` | Когда произошло событие |
| `transport_type` | String | `"Автобус 101"` | Тип транспорта (если применимо) |
| `transport_route_from`| String | `"ул. Ленина"` | Начало маршрута |
| `transport_route_to` | String | `"Центр"` | Конец маршрута |
| `created_at` | DateTime | `now()` | Дата создания записи |
| `expires_at` | DateTime | `now() + 30 days` | Дата автоматического удаления |

---

## 2. Таблица `categories` (Категории)
Иерархическая структура категорий.

| Имя поля | Тип | Значение / Пример | Примечание |
| :--- | :--- | :--- | :--- |
| `id` | Integer | `1` | Первичный ключ |
| `name` | String | `"cat_pets_"` | Ключ для перевода |
| `slug` | String | `"cat_pets"` | Уникальный текстовый ID |
| `icon` | String | `"🐾"` | Эмодзи или имя иконки |
| `parent_id` | Integer | `NULL` | Ссылка на родительскую категорию |

---

## 3. Таблица `users` (Пользователи)
Данные зарегистрированных пользователей.

| Имя поля | Тип | Значение / Пример | Примечание |
| :--- | :--- | :--- | :--- |
| `id` | Integer | `1` | Первичный ключ |
| `email` | String | `"user@mail.ru"` | Уникальный email (логин) |
| `hashed_password` | String | `"$pbkdf2..."` | Хэш пароля |
| `full_name` | String | `"Иван Иванов"` | Имя пользователя |
| `phone` | String | `"+7999..."` | Телефон |
| `is_verified` | Boolean | `true` | Подтвержден ли email |
| `verification_token`| String | `uuid` | Токен для ссылки активации |
| `created_at` | DateTime | `now()` | Дата регистрации |

---

## 4. Таблица `messages` (Отклики)
Сообщения, отправленные владельцам объявлений.

| Имя поля | Тип | Значение / Пример | Примечание |
| :--- | :--- | :--- | :--- |
| `id` | Integer | `1` | Первичный ключ |
| `item_id` | Integer | `42` | Ссылка на объявление |
| `content` | Text | `"Я нашел ваши ключи!"` | Текст сообщения |
| `contact_info` | String | `"+7900..."` | Контакты нашедшего |
| `photos_urls` | JSON | `["url1", "url2"]` | Список фото-подтверждений |
| `created_at` | DateTime | `now()` | Дата отправки |

---

## 5. Таблица `telegram_users` (Связка Telegram)
Кэш для автоматического определения Telegram ID по номеру телефона.

| Имя поля | Тип | Значение / Пример | Примечание |
| :--- | :--- | :--- | :--- |
| `id` | Integer | `1` | Первичный ключ |
| `phone` | String | `"79991234567"` | Очищенный номер (только цифры) |
| `telegram_id` | String | `"123456789"` | ID пользователя в Telegram |
| `created_at` | DateTime | `now()` | Дата первого контакта с ботом |
