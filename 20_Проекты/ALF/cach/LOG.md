# ALF: Настройка локальной среды (12.05.2026 - 13.05.2026)

## Основные изменения за сессию
Работа была сфокусирована на обеспечении возможности локальной разработки и дебага кода вне Docker-контейнеров.

### 1. Конфигурация IDE (VS Code)
- Создан `.vscode/launch.json`: добавлена конфигурация "ALF: Full Stack (Local)", позволяющая запускать Backend (FastAPI), Frontend (Next.js) и Telegram Bot одновременно в режиме отладки.
- Создан `.vscode/settings.json`: прописаны пути к интерпретатору `venv`, настроен `PYTHONPATH` и `extraPaths` для корректного разрешения импортов (исправлены ошибки "unresolved import" для папки `app`).

### 2. Исправление зависимостей (Backend)
- Установлена библиотека `email-validator` в виртуальное окружение. Без нее Pydantic v2 падал с `ImportError` при попытке инициализировать схемы пользователей (`UserCreate`, `UserRead`).

### 3. Отладка подключения к БД
- Проведен глубокий анализ проблем подключения к PostgreSQL.
- **Обнаружен конфликт портов**: Порт `5432` на хосте занят локальной службой Windows (`postgres.exe`), что мешало доступу к Docker-контейнеру `alf_db`.
- В конфигурации дебага адрес базы изменен с `localhost` на `127.0.0.1` для стабильности на Windows.
- Создан проверочный скрипт `backend/test_db.py` для диагностики проблем кодировки при выводе ошибок авторизации.

### 4. Текущий статус
- Среда готова к запуску.
- **Инструкция для продолжения**: Остановить службу `postgresql` в `services.msc`, чтобы освободить порт 5432 для Docker, затем нажать F5 в VS Code.
