# ALF: Административная панель и Лог изменений (09.05.2026)

## 🛠️ Руководство администратора

### Как попасть в админку
Доступ предоставляется только пользователям с флагом `is_admin: true` в базе данных.
1. Авторизуйтесь на сайте.
2. Откройте окно своего профиля (кнопка с именем пользователя в шапке).
3. Нажмите кнопку **"Админ-панель"** (выделена фиолетовым цветом).

### Возможности модерации
1. **Статистика в реальном времени**:
   - Общее количество объявлений в системе.
   - Количество успешно завершенных дел (вещь возвращена).
   - Общее число зарегистрированных пользователей.
   - Динамика новых объявлений за последние 7 дней.
2. **Черный список (Blacklist)**:
   - Позволяет банить по Email или номеру телефона.
   - Работает даже для незарегистрированных пользователей (превентивный бан).
   - Забаненные контакты не могут создавать новые аккаунты или объявления.
3. **Прямое удаление с карты**:
   - Администратор видит красную кнопку **"Удалить (Админ)"** в любом открытом объявлении, даже если оно не его. Это позволяет мгновенно чистить спам или неактуальные данные.

## 📝 Лог изменений (08.05.2026 - 09.05.2026)

### 1. Стабильность и Карта
- **Оптимизация MapComponent**: Компонент обернут в `React.memo`, а обработчики событий — в `useCallback`. Это устранило ошибку `appendChild` и падение карты при перемещении.
- **Устранение бесконечных циклов**: Исправлена логика `fetchItems`, которая вызывала рекурсивные обновления при изменении границ карты. Теперь используются `useRef` для хранения координат.

### 2. Интерфейс (UI/UX)
- **Скроллинг боковых панелей**: Добавлены стили `100vh` и `overflow-y: auto` для панелей просмотра и создания объявлений. Теперь длинные тексты и списки откликов можно прокручивать.
- **Неблокирующий интерфейс**: Панели закреплены справа, что позволяет продолжать работу с картой (зум, панорамирование), когда панель открыта.
- **Умные фильтры**:
  - Кнопка "Неделя" теперь работает как переключатель (Toggle).
  - Добавлена кнопка "Показать все объявления" при пустом поиске, которая автоматически отключает фильтрацию по области видимости.
  - Добавлен фильтр "Показать закрытые" для режима "Мои объявления".

### 3. Функционал и Безопасность
- **Автоматическое владение**: Залогиненные пользователи распознаются как владельцы по Email/Телефону. Пароль для редактирования/закрытия своих объявлений больше не требуется.
- **Удаление/Редактирование**: Исправлены ошибки "Invalid password" при попытке закрыть свое объявление.
- **Админ-сервис**: 
  - Реализована backend-логика проверки прав администратора.
  - Создана таблица `blacklist` и механизмы проверки при регистрации.
  - Реализованы API-эндпоинты для получения статистики и модерации.

### 4. Исправление багов
- Удалена зависимость `framer-motion`, вызывавшая ошибки сборки в контейнере.
- Исправлены опечатки в бэкенде (`toLowerCase` -> `lower`).
- Добавлены пропущенные импорты моделей (`User`).
- Исправлена верстка (незакрытые теги в JSX).
