# Yandex Video Ad Cleaner

Локальное расширение для Яндекс Браузера, которое блокирует рекламные сетевые запросы и скрывает рекламные контейнеры на страницах Яндекс Видео.

## Установка

### Вариант 1: готовый ярлык

На рабочем столе создан ярлык `Yandex Browser Ad Cleaner.lnk`. Он запускает Яндекс Браузер с подключенным расширением.

### Вариант 2: вручную

1. Открой в Яндекс Браузере страницу `browser://extensions`.
2. Включи режим разработчика.
3. Нажми **Загрузить распакованное расширение**.
4. Выбери папку `C:\Oburec\Antigravity\Projects\AGrav\20_Проекты\YandexVideoAdCleaner\extension`.
5. Открой видео: `https://yandex.ru/video/preview/9905979477529766275`.

## Что делает расширение

- Блокирует типовые рекламные домены Яндекса и AdFox через `declarativeNetRequest`.
- Блокирует найденный рекламный media-домен `lotory.top`.
- Блокирует рекламный модуль VAST у embed-плеера `nmcorp.video`.
- Скрывает рекламные блоки, iframe и баннеры по явным признакам в `id`, `class`, `data-*`, `title` и `aria-label`.
- Автоматически нажимает кнопку пропуска рекламы JWPlayer (`jw-skip`, `aria-label="Пропустить"`).
- Вызывает `jwplayer(...).skipAd()` в контексте страницы, если JWPlayer API доступен.
- Пока кнопка пропуска заблокирована таймером, пытается ускорить рекламный ролик.
- Если рекламный ролик загружен с `cdn.lotory.top`, останавливает и очищает `src` текущего рекламного `video`.
- Перехватывает попытки JWPlayer заново назначить `video.src` на `cdn.lotory.top`.
- Работает внутри embed-плеера `nmcorp.video`, который используется страницей Яндекс Видео.
- Удаляет `advertising` из конфигурации JWPlayer перед `player.setup(...)`, если успевает выполниться до инициализации.
- Помечает промежуточный sandbox iframe `yastatic.net/video-player` атрибутом `data-yvac-yastatic-frame`.
- Наблюдает за динамической подгрузкой страницы и повторяет очистку после изменения DOM.

## Ограничения

Яндекс может менять верстку и адреса рекламных запросов. Если реклама снова появится, нужно открыть DevTools, найти новый рекламный домен или CSS-признак блока и добавить его в `extension/rules.json`, `extension/styles.css` или `extension/content.js`.
