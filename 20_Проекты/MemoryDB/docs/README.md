# Локальная векторная память ИИ-ассистента (MemoryDB)

Проект реализует полностью локальную, быструю и автономную векторную (семантическую) память для ИИ-ассистента Antigravity. Позволяет сохранять важные факты, решения, особенности проектов и выполнять поиск по их смыслу.

---

## 🛠 Технический стек
- **Язык**: Python 3.10+ (проверено на Python 3.14)
- **Векторная база**: `qdrant-client` в локальном режиме (`local mode` / SQLite + NumPy)
- **Локальные эмбеддинги**: `fastembed` (с использованием ONNX модели `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` для поддержки русского и английского языков)
- **Протокол**: Model Context Protocol (MCP) через `stdio` транспорт

## Индекс исходников оригинального Recorder

MemoryDB содержит отдельную коллекцию Qdrant `source_code`. Индексатор читает
только необходимые каталоги `D:\works\windev-v3.9`: ядро Recorder (`mr`,
`rc_core`, `rc_guisrv`, `rc_conui`, `rc_ctrpn`, `rc_utils`), SDK и исходники
приборов, используемые RecorderLnx. Оригинальные файлы никогда не изменяются.

Каждый чанк хранит абсолютный путь, имя найденного символа и точный диапазон
строк. MCP предоставляет команды:

- `sync_original_recorder_sources(dry_run=False)` — обновить индекс по SHA-256;
- `search_original_recorder_sources(query, limit=8)` — найти фрагменты по
  смыслу. Результат поиска служит навигацией и должен проверяться чтением
  оригинального файла по возвращённым строкам.

## 🚀 Установка и Запуск

### 1. Установка зависимостей
Установите библиотеки с помощью pip:
```bash
pip install -r requirements.txt
```

### 2. Тестирование
Для проверки корректности работы базы и генерации эмбеддингов запустите автономный тест:
```bash
run_test.bat
```
Скрипт добавит тестовый факт о Lazarus cp1251 кодировке и найдет его по смысловому запросу «как исправить знаки вопроса в русском тексте LCL на Lazarus?».

## 🔗 Интеграция в среду разработки (MCP)

Добавьте конфигурацию сервера в файл настроек MCP (`mcp_config.json` или `settings.json` вашей IDE):

```json
{
  "mcpServers": {
    "local-memory-db": {
      "command": "python",
      "args": ["d:/works/AGrav/20_Проекты/MemoryDB/src/main.py"],
      "env": {
        "PYTHONPATH": "d:/works/AGrav/20_Проекты/MemoryDB"
      }
    }
  }
}
```

## ⚙️ Доступные инструменты (Tools)

После интеграции ИИ-ассистент получит доступ к следующим инструментам:

1. **`save_memory_fact`**
   - **Описание**: Сохранить факт в память.
   - **Параметры**:
     - `fact` (str): Текст факта (например: "В Delphi для потоков нельзя аллоцировать память внутри DoTick").
     - `tags` (list[str]): Метки для фильтрации (например: ["delphi", "threads"]).
     - `project_context` (str, опционально): Контекст конкретного проекта (например: "RecorderLnx", "ALF").

2. **`search_memory_facts`**
   - **Описание**: Семантический поиск по сохраненным фактам.
   - **Параметры**:
     - `query` (str): Смысловой запрос (например: "проблемы с потоками").
     - `limit` (int): Максимальное количество результатов (по умолчанию 5).
     - `tags` (list[str], опционально): Фильтр по тегам.
     - `project_context` (str, опционально): Фильтр по контексту проекта.

3. **`delete_memory_fact`**
   - **Описание**: Удалить факт по его UUID.
   - **Параметры**:
     - `fact_id` (str): Уникальный идентификатор UUID.

4. **`list_memory_facts`**
   - **Описание**: Вывести список последних сохраненных фактов.
   - **Параметры**:
     - `limit` (int): Количество записей (по умолчанию 50).
