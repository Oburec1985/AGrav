# 🤖 Инструкция для AI (README)

Добро пожаловать в AGrav. Это внешняя память и операционная среда твоего USER-а. 
Твоя задача — поддерживать порядок и развивать эту базу знаний.

## 🚀 С чего начать?
1. **Прочти [Оглавление](./00_Система/Оглавление.md)**: Пойми структуру разделов. Подгружай данные в структуру или из нее по мере необходимости;
2. **Изучи [Скиллы ИИ](./00_Система/Скиллы_ИИ.md)**: Здесь твои инструкции по стилю и накопленные навыки. Запиши их себе в системные навыки (Skills).
3. **Семантический Поиск и Память**: Все знания и заметки AGrav проиндексированы в локальной векторной базе данных Qdrant. Вместо чтения больших файлов целиком, используй инструмент семантического поиска `search_vault_notes` для нахождения нужных чанков. Это экономит контекстное окно и токены. Подробности использования смотри в навыке [🔍 Рекурсивный поиск RLM](./00_Система/skills/rlm-search/SKILL.md).
   > [!IMPORTANT]
   > Локальная векторная база Qdrant (`memory_store.db`) исключена из Git. При клонировании репозитория или переносе на новое место необходимо выполнить переиндексацию локально. Для этого запусти инструмент [Векторный Индексатор БЗ](./00_Система/Инструменты/Индексатор_БЗ.md) или выполни MCP-команду `sync_vault_notes()`.
4. **Ведение Истории**: Любое значимое изменение в любом проекте ОБЯЗАТЕЛЬНО фиксируется в файле `90_Архив/История_изменений.md` с сохранением систематизированного промпта, по которому оно получено (в коротком понятном виде). Новые записи всегда добавляются В НАЧАЛО файла (сразу под заголовком).
5. **Проверь [Цех Проектов](./20_Проекты/Цех_Проектов.md)**: Найди проект, над которым сейчас идет работа.

## 📌 Твои обязанности
1. **Wiki-стандарт**: Используй стандартный Markdown для ссылок. Избегай платформо-зависимых функций.
2. **Карта связей**: Поддерживай актуальность [Relationships](./00_Система/Relationships.md).
3. **Актуальность**: Если информация устарела — исправляй её. Поддерживай порталы разделов в чистоте.
4. **Логирование**: После завершения важного этапа обнови историю в [История_изменений.md](./90_Архив/История_изменений.md).
